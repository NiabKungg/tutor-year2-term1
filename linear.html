1. ระบบเชิงเส้นและเมทริกซ์

1.1 เมทริกซ์และระบบเชิงเส้น

นิยามสำคัญ
  • m × n matrix: ตารางจำนวนจริง m แถว n หลัก, สมาชิกตำแหน่งแถวที่ i หลักที่ j เขียน a_ij (แถวก่อนหลักเสมอ)
  • สมาชิกทแยงมุม (diagonal entry) คือ a11, a22, ... บนเส้นทแยงมุมหลัก (main diagonal)
  • เมทริกซ์จัตุรัส (square matrix): m = n / เวกเตอร์แถว 1×n, เวกเตอร์หลัก m×1 / zero matrix: ทุกสมาชิกเป็น 0
  • สมการเชิงเส้น: รูป a1x1 + a2x2 + ... + anxn = b ไม่มีกำลัง ไม่มีผลคูณระหว่างตัวแปร เช่น 4x1 - 5x2 + 5 = x3 เป็นสมการเชิงเส้น แต่ 4x1x2 = x3 - 2 และ x1 = √x2 + 3 ไม่ใช่
  • ผลเฉลย (solution) คือชุดจำนวนจริงที่ทำทุกสมการเป็นจริง, สองระบบสมมูลกัน (equivalent) ถ้ามีเซตผลเฉลยเดียวกัน
  • coefficient matrix = ตัวเลข a_ij เท่านั้น / augmented matrix [A | b] = เอาหลักค่าคงตัวต่อท้าย

ผลลัพธ์ของระบบเชิงเส้นมีได้แค่ 3 แบบ:

  1. ไม่มีผลเฉลย, ระบบเป็น inconsistent (ไม่ต้องกัน)
  2. มีผลเฉลยชุดเดียว
  3. มีผลเฉลยอนันต์ชุด (แบบ 2, 3 เรียกรวมว่า consistent (ต้องกัน))

การดำเนินการแถวขั้นมูลฐาน (elementary row operations)

ชนิดสัญลักษณ์ความหมาย

เมทริกซ์ B ที่ได้จาก A โดยการดำเนินการแถว เรียกว่า สมมูลแถว (row equivalent) เขียน A ∼ B ระบบที่เมทริกซ์แต่งเติมสมมูลกันมีเซตผลเฉลยเดียวกัน การบวก/คูณสเกลาร์ของเมทริกซ์ทำได้เฉพาะมิติเดียวกัน โดย c_ij = a_ij + b_ij และมีสมบัติ c(A+B) = cA + cB, 1A = A, A + (-A) = 0

1.2 เมทริกซ์ขั้นบันไดและตำแหน่งตัวหลัก (Echelon Form และ Pivot)

echelon form ต้องมีเงื่อนไข 3 ข้อ:

  1. แถวที่มีแต่ 0 ล้วนต้องอยู่ต่ำกว่าแถวที่มีตัวไม่ใช่ 0
  2. ตัวแรกที่ไม่ใช่ 0 ของแต่ละแถว เรียก สมาชิกนำ (leading entry) สมาชิกนำของแถวที่ต่ำกว่าต้องอยู่หลักทางขวาของสมาชิกนำแถวบน
  3. ถ้าสมาชิกนำอยู่หลักใด สมาชิกแถวล่างกว่าในหลักนั้นต้องเป็น 0

reduced echelon form เพิ่มอีก 2 เงื่อนไข:

  1. สมาชิกนำทุกตัวต้องเป็น 1 (เรียก 1 ตัวนำ หรือ leading 1)
  2. ในหลักที่มี 1 ตัวนำ สมาชิกอื่นในหลักนั้นต้องเป็น 0
ประเด็นสำคัญ
  • ทฤษฎี: ทุกเมทริกซ์ลดรูปเป็นขั้นบันไดได้ และลดรูปเป็นขั้นบันไดลดรูปได้แบบเดียวเท่านั้น
  • pivot position / pivot column: ตำแหน่ง/หลักที่มีสมาชิกนำในรูปขั้นบันได
  • basic variable: ตัวแปรที่สมนัยกับหลักตัวหลัก / free variable: ตัวแปรที่เหลือ
  • general solution: เขียนตัวแปรพื้นฐานในรูปของค่าคงตัวและตัวแปรเสรี
มักออกสอบ: ทฤษฎีบทตัดสินจำนวนผลเฉลย
  • Existence Theorem: ระบบมีผลเฉลย ก็ต่อเมื่อ หลักขวาสุดของเมทริกซ์แต่งเติมไม่ใช่หลักตัวหลัก คือรูปขั้นบันไดไม่มีแถวรูป [0 0 ... 0 | b] เมื่อ b ≠ 0
  • Uniqueness Theorem: ถ้ามีผลเฉลย, มีชุดเดียว ⟺ ไม่มีตัวแปรเสรี (ทุกหลักยกเว้นหลักขวาสุดเป็นหลักตัวหลัก) / มีอนันต์ชุด ⟺ มีตัวแปรเสรีอย่างน้อย 1 ตัว

วิธีแก้ระบบเชิงเส้นทีละขั้น:

  1. เขียนเมทริกซ์แต่งเติม [A | b]
  2. ลดรูปจนได้รูปขั้นบันได แล้วใช้ Existence Theorem ตรวจว่ามีผลเฉลยหรือไม่
  3. ถ้ามีผลเฉลย ลดรูปต่อจนได้รูปขั้นบันไดลดรูป แล้วระบุตัวแปรพื้นฐาน/ตัวแปรเสรี
  4. เขียนผลเฉลยทั่วไป (parametric vector form)

1.3 การรวมเชิงเส้น, Span และสมการเมทริกซ์

  • R^m = เซตของเวกเตอร์หลักมิติ m ทั้งหมด, เวกเตอร์ศูนย์เขียน 0
  • linear combination: y = c1v1 + c2v2 + ... + cpvp โดย c_i เรียก น้ำหนัก (weight)
  • Span{v1, ..., vp} = เซตของการรวมเชิงเส้นทั้งหมด {c1v1 + ... + cpvp : ci ∈ R}, ถ้า Span = R^m เรียกว่าเวกเตอร์แผ่ทั่ว R^m
  • ภาพเรขาคณิต: Span{v} = เส้นตรงผ่านจุดกำเนิด, Span{v1, v2} ที่ไม่เป็นพหุคูณกัน = ระนาบผ่านจุดกำเนิดใน R^3
  • สมการเวกเตอร์ x1v1 + x2v2 + ... + xpvp = b มีผลเฉลยเดียวกับระบบที่มีเมทริกซ์แต่งเติม [v1 v2 ... vp | b]
  • Ax = x1v1 + x2v2 + ... + xnvn คือการรวมเชิงเส้นของหลักของ A ด้วยน้ำหนักสมาชิกของ x
  • เมทริกซ์เอกลักษณ์ I_n: เมทริกซ์ทแยงมุมมี 1 บนทแยงมุมหลัก มีสมบัติ In·x = x
บทแทรกและทฤษฎีบทที่ใช้บ่อย
  • Ax = b มีผลเฉลย ⟺ b เป็นการรวมเชิงเส้นของหลักของ A ⟺ [A | b] ต้องกัน
  • ทฤษฎีบท 1.3.4 (สมมูลกัน 3 ข้อ): สำหรับทุก b ∈ R^m สมการ Ax = b มีผลเฉลย ⟺ หลักของ A แผ่ทั่ว R^m ⟺ A มีตำแหน่งตัวหลักในทุกแถว

การคูณเมทริกซ์และ transpose

  • AB มีความหมายเมื่อ จำนวนหลักของ A = จำนวนแถวของ B (conformable)
  • วิธีคิดทีละชิ้น: (AB)_ik = ai1b1k + ai2b2k + ... + ainbnk คือ แถวของ A คูณหลักของ B (row by column)
  • สมบัติ: A(BC) = (AB)C, A(B+C) = AB + AC, (B+C)A = BA + CA, Im·A = A = A·In
  • transpose AT คือสลับแถวกับหลัก มิติกลับด้าน: (A^T)^T = A, (A+B)^T = A^T + B^T, (rA)^T = rA^T, (AB)^T = B^T A^T (ผลคูณกลับอันดับ)
  • symmetric matrix: เมทริกซ์จัตุรัสที่ A^T = A (I, diagonal matrix, scalar matrix เป็นสมมาตรเสมอ)
ข้อผิดพลาดที่พบบ่อย (การคูณเมทริกซ์)
  • AB ≠ BA โดยทั่วไป (BA อาจคูณกันไม่ได้ด้วยซ้ำ) เช่น T·S ≠ S·T
  • ถ้า AB = 0 สรุปไม่ได้ว่า A = 0 หรือ B = 0, ถ้า AB = AC ตัด A ออกไม่ได้ (สรุป B = C ไม่ได้)
  • ตัวอย่าง: [[1,1],[0,0]] · [[2,3],[-2,-3]] = [[0,0],[0,0]] ทั้งที่ไม่มีเมทริกซ์ตัวใดเป็นศูนย์

1.4 ระบบเอกพันธุ์และอิสระเชิงเส้น

  • ระบบเอกพันธุ์ (homogeneous): Ax = 0 มีผลเฉลยชัด (trivial solution) = 0 เสมอ
  • ผลเฉลยไม่ชัด (nontrivial solution) เกิดเมื่อมีตัวแปรเสรี คือ A มีหลักที่ไม่เป็นหลักตัวหลัก
  • เขียนผลเฉลยทั้งหมดเป็น parametric vector form เช่น x = t·(5,1,1) เมื่อ t ∈ R
  • ระบบไม่เอกพันธุ์ Ax = b: ผลเฉลยทั่วไป = ผลเฉลยเฉพาะ p + ผลเฉลยทั่วไปของระบบเอกพันธุ์ vh นั่นคือ x = p + vh
  • เรขาคณิต: เซตผลเฉลยของระบบไม่เอกพันธุ์ = เส้น/ระนาบขนานกับของระบบเอกพันธุ์ (ของเอกพันธุ์ผ่านจุดกำเนิด)

อิสระเชิงเส้น (linear independence): เซต {v1, ..., vp} อิสระเชิงเส้น ⟺ สมการเอกพันธุ์ x1v1 + ... + xpvp = 0 มีเพียงผลเฉลยชัด ถ้าไม่อิสระ จะมี c_i ไม่ใช่ศูนย์พร้อมกันทำให้การรวมเชิงเส้นเป็นศูนย์ ก็คือมีเวกเตอร์หนึ่งเป็นการรวมเชิงเส้นของตัวอื่น วิธีเช็ก: สร้าง A = [v1 ... vp] แล้วลดรูป, อิสระ ⟺ ทุกหลักเป็นหลักตัวหลัก

มักออกสอบ: ข้อสังเกตสำเร็จรูปเรื่องอิสระเชิงเส้น
  1. เซตที่มีเวกเตอร์ศูนย์ → ไม่อิสระเชิงเส้น
  2. {v} อิสระ ⟺ v ≠ 0
  3. {v1, v2} ไม่อิสระ ⟺ v1 = c·v2 (เป็นพหุคูณสเกลาร์กัน)
  4. มี p เวกเตอร์ใน R^m โดย p > m → ไม่อิสระเชิงเส้น (หลักมากกว่าแถว ทุกหลักเป็นหลักตัวหลักไม่ได้)
ข้อผิดพลาดที่พบบ่อย (บทที่ 1)
  • คิดว่ารูปขั้นบันไดของเมทริกซ์แบบเดียว: จริง ๆ รูปขั้นบันไดมีได้หลายแบบ มีเพียงรูปขั้นบันไดลดรูปที่แบบเดียว
  • เงื่อนไข 1 ตัวนำและศูนย์เหนือ-ใต้ ใช้กับขั้นบันไดลดรูปเท่านั้น รูปขั้นบันไดธรรมดาไม่ต้องมีสมาชิกนำเป็น 1
  • ลืมดำเนินการแถวกับหลักขวาสุดของเมทริกซ์แต่งเติมด้วย
  • เมื่อได้แถว [0 0 0 | b] โดย b ≠ 0 ต้องสรุปว่า "ไม่มีผลเฉลย" ไม่ใช่ "มีตัวแปรเสรี"

2. การแยกตัวประกอบและการแปลงเชิงเส้น

2.1 การแปลงเชิงเส้นและเมทริกซ์มาตรฐาน

  • matrix transformation: T(x) = Ax โดย A เป็น m×n, T: R^n → R^m
  • linear transformation: T(u + v) = T(u) + T(v) และ T(cu) = cT(u) (รวมเขียนได้ T(cu + dv) = cT(u) + dT(v))
  • ผลตามทันที: T(0) = 0 และ T(-v) = -T(v), เป็นวิธีเช็กเร็วว่า T ไม่ใช่การแปลงเชิงเส้น
  • ทุกการแปลงเมทริกซ์เป็นการแปลงเชิงเส้น และทุกการแปลงเชิงเส้นเป็นการแปลงเมทริกซ์
  • ตัวอย่างไม่เป็นการแปลงเชิงเส้น: T(x) = sin x, T(x) = |x| + |y|, T(x1,x2) = (x1+x2, x2+4) (เพราะ T(0) ≠ 0)

เมทริกซ์มาตรฐาน (standard matrix) ของ T:

A = [ T(e1)  T(e2)  ...  T(en) ]     (หลักที่ j = T(ej) เมื่อ ej มาจากหลัก j ของ In)

เพราะ x = x1e1 + x2e2 + ... ดังนั้น T(x) = x1T(e1) + x2T(e2) + ... = Ax ถ้าโจทย์ให้ T(e1), T(e2), ... มาต่อเรียงหลักจะได้ A ทันที

สมบัติทั่วถึง (onto) และหนึ่งต่อหนึ่ง (one-to-one)
  • T ทั่วถึง R^m ⟺ หลักของ A แผ่ทั่ว R^m ⟺ A มี pivot ในทุกแถว
  • T มีสมบัติ 1-1 ⟺ T(x) = 0 มีเพียงผลเฉลยชัด ⟺ หลักของ A อิสระเชิงเส้น ⟺ A มี pivot ในทุกหลัก
  • ผลตามทันที: ไม่มีการแปลงเชิงเส้น R^3 → R^5 ที่ทั่วถึงได้ (pivot มีได้ไม่เกิน 3 แต่มี 5 แถว)
ข้อผิดพลาดที่พบบ่อย (2.1)
  • สลับเงื่อนไข "pivot ทุกแถว" (ทั่วถึง) กับ "pivot ทุกหลัก" (1-1)
  • วิธีจำ: 1-1 ต้อง "ยิงคนละเป้าหมาย" → ดูหลัก (จำนวนเวกเตอร์/ตัวแปร), ทั่วถึงต้อง "ครอบคลุมทุกแถว" → ดูแถว

2.2 ปริภูมิย่อย, Col A, Nul A, ฐานหลัก และ Rank

ปริภูมิย่อย (subspace) H ของ R^m ต้องมี 3 สมบัติ: (1) 0 ∈ H (2) ปิดบวก: u, v ∈ H ⇒ u+v ∈ H (3) ปิดคูณสเกลาร์: u ∈ H ⇒ cu ∈ H โดย Span{v1, ..., vp} เป็นปริภูมิย่อยเสมอ

  • Col A (column space) = Span ของหลักของ A = {Ax : x ∈ R^n} เป็นเรนจ์ของการแปลง x → Ax
  • Nul A (null space) = เซตผลเฉลยของ Ax = 0 เป็นปริภูมิย่อยของ R^n
  • b ∈ Col A ⟺ ระบบ Ax = b มีผลเฉลย
  • ฐานหลัก (basis) ของ H = เซตที่ (1) อิสระเชิงเส้น และ (2) แผ่ทั่ว H, ฐานหลักมาตรฐานของ R^m = {e1, ..., em}
  • ฐานหลักของ Col A = เซตของหลักตัวหลักของ A ต้นฉบับ (ไม่ใช่หลักของรูปลดรูป)
  • ฐานหลักของ Nul A = เวกเตอร์ที่ได้จากตัวแปรเสรีหลังลดรูปเป็นขั้นบันไดลดรูป
Rank และ Nullity
  • rank A = dim Col A = จำนวนหลักตัวหลัก
  • nullity A = dim Nul A = จำนวนตัวแปรเสรี = จำนวนหลักที่ไม่ใช่หลักตัวหลัก
  • Rank Theorem: rank A + nullity A = n (จำนวนหลัก) เช่น A ขนาด 10×12 ที่ nullity = 7 ⇒ rank = 12 - 7 = 5

วิธีหาฐานหลัก Col A, Nul A, rank, nullity ทีละขั้น:

  1. ลดรูป A จนได้รูปขั้นบันได แล้วดูว่าหลักใดเป็นหลักตัวหลัก
  2. Col A: หยิบหลักจาก A เดิมที่ตำแหน่งเดียวกับหลักตัวหลักมาเป็นฐานหลัก, rank A = จำนวนหลักตัวหลัก
  3. Nul A: ลดรูปต่อจนขั้นบันไดลดรูป แก้ Ax = 0 เขียนตัวแปรพื้นฐานในรูปตัวแปรเสรี รวมเป็นเวกเตอร์อิงตัวแปรเสรี, nullity A = จำนวนเวกเตอร์ในฐานหลัก
  4. ตรวจ: rank + nullity = จำนวนหลัก

ตัวอย่างคำนวณเต็มขั้นตอนดูที่ ข้อ 20 ของแบบทดสอบ

ข้อผิดพลาดที่พบบ่อย (2.2)
  • เอาหลักของรูปลดรูปมาเป็นฐานหลัก Col A: ผิด! ต้องใช้หลักของเมทริกซ์ต้นฉบับ
  • จำ Rank Theorem เป็น "rank + nullity = จำนวนแถว": ผิด! ต้องเป็นจำนวนหลัก
  • ลืมว่า Nul A เป็นปริภูมิย่อยของ R^n (มิติเท่าจำนวนหลัก) ไม่ใช่ R^m

2.3 เมทริกซ์ผกผัน (Inverse Matrix)

A ขนาด n มี inverse C เมื่อ AC = In = CA เขียน C = A-1 (มีได้ตัวเดียว) มี inverse เรียก nonsingular (ไม่เอกฐาน) ไม่มีเรียก singular (เอกฐาน)

สูตร 2×2 (จำทันที):

A = [[a, b], [c, d]]   จะได้   A^-1 = (1/(ad - bc)) · [[ d, -b ], [ -c, a ]]   เมื่อ ad - bc ≠ 0

เทคนิค: สลับสมาชิกบนเส้นทแยงมุมหลัก, เปลี่ยนเครื่องหมายสมาชิกนอกเส้นทแยงมุม, หารด้วย determinant

ตัวอย่าง: หา inverse ของเมทริกซ์ 2×2 และใช้แก้ระบบ
  1. ให้ A = [[2, 5], [-3, -7]], คำนวณ det = 2(-7) - 5(-3) = -14 + 15 = 1 ≠ 0 จึงมี inverse
  2. สลับทแยงหลัก เปลี่ยนเครื่องหมายนอกทแยง หารด้วย 1: A^-1 = [[-7, -5], [3, 2]]
  3. ใช้แก้ระบบ 2x1 + 5x2 = -1, -3x1 - 7x2 = 1 ซึ่งเป็น Ax = b เมื่อ b = (-1, 1)
  4. x = A^-1 b = [[-7, -5], [3, 2]] · [[-1], [1]] = [[7 - 5], [-3 + 2]] = [[2], [-1]]
  5. ได้ x1 = 2, x2 = -1 (ตรวจ: 2(2) + 5(-1) = -1 และ -3(2) - 7(-1) = 1 ถูกต้อง)
สมบัติของ inverse
  • (A^-1)^-1 = A และ (A^T)^-1 = (A^-1)^T
  • (AB)^-1 = B^-1 A^-1 (กลับอันดับเหมือน transpose)
  • (kA)^-1 = (1/k)A^-1 และ AI = IA = A, AA^-1 = A^-1 A = I
  • elementary matrix = เมทริกซ์ได้จาก I โดยการดำเนินการแถว 1 ครั้ง, การคูณด้านซ้าย EA ให้ผลเท่ากับดำเนินการแถวนั้นกับ A

วิธีหา inverse ขนาด n (วิธีเมทริกซ์แต่งเติม): (1) เขียน [A | In] (2) ดำเนินการแถวจนด้านซ้ายเป็น In ด้านขวาคือ A-1 (3) ถ้าลดรูปซ้ายไม่ได้ In (มีแถวศูนย์) แสดงว่า A ไม่มี inverse

อ่านเพิ่ม: ทฤษฎีบทเมทริกซ์หาตัวผกผันได้ (Invertible Matrix Theorem)

สำหรับ A ขนาด n ข้อความต่อไปนี้สมมูลกันทั้งหมด (จริงพร้อมกันหรือเท็จพร้อมกัน):

  1. A หา inverse ได้
  2. A ∼ In (สมมูลแถวกับเมทริกซ์เอกลักษณ์)
  3. A มี pivot ครบ n ตำแหน่ง
  4. Ax = 0 มีเพียงผลเฉลยชัด
  5. หลักของ A อิสระเชิงเส้น
  6. x → Ax มีสมบัติ 1-1
  7. Ax = b มีผลเฉลยทุก b
  8. หลักของ A แผ่ทั่ว R^n
  9. x → Ax ทั่วถึง
  10. มี C ที่ CA = In / มี D ที่ AD = In
  11. A^T หา inverse ได้
  12. หลักของ A เป็นฐานหลักของ R^n
  13. Col A = R^n
  14. rank A = n
  15. Nul A = {0}
  16. nullity A = 0
ตัวอย่าง: เช็กเร็วว่า A หา inverse ได้หรือไม่
  1. หา h ที่ทำให้ [[1, -7, h], [2, 1, 1], [1, 3, 2]] หา inverse ได้
  2. ลดรูป: R2 - 2R1 ได้ [0, 15, 1-2h], R3 - R1 ได้ [0, 10, 2-h]
  3. R3 - (2/3)R2 ได้แถวสุดท้าย [0, 0, (h+4)/3]
  4. จะมี pivot ครบ 3 ตำแหน่งก็ต่อเมื่อ h + 4 ≠ 0 ดังนั้น h ≠ -4

2.4 ดีเทอร์มิแนนต์ (Determinant)

  • minor Mij(A) = เมทริกซ์ที่ได้จากการตัดแถว i และหลัก j ออก
  • cofactor: Cij(A) = (-1)^(i+j) · det Mij(A) (ตารางเครื่องหมาย + - + / - + - / + - +)
  • det A หาได้จากการกระจายโคแฟกเตอร์ (cofactor expansion) ตามแถวใด ๆ หรือหลักใด ๆ: det A = ai1·Ci1 + ai2·Ci2 + ... + ain·Cin

กรณีพื้นฐาน:

  • 1×1: det [a11] = a11 / 2×2: det [[a,b],[c,d]] = ad - bc
  • 3×3 สูตรลัด (แนวเฉียง): det = (a11a22a33 + a12a23a31 + a13a21a32) - (a31a22a13 + a32a23a11 + a33a21a12)
  • เมทริกซ์สามเหลี่ยม (triangular): det = ผลคูณของสมาชิกบนเส้นทแยงมุมหลัก
  • เทคนิค: กระจายตามแถว/หลักที่มีศูนย์มากที่สุดเพื่อประหยัดการคำนวณ (โปรแกรมหาดีเทอร์มิแนนต์ที่ใช้ในชั้นเรียนก็ป้อนแถว/หลัก/สมาชิกแล้วคำนวณด้วยหลักการเดียวกัน)
ตัวอย่าง: det ของเมทริกซ์สามเหลี่ยม
  1. det [[-4, 0, 0, 0], [0, 2, 0, 0], [1, 2, -3, 0], [-2, 4, 2, -1]] เป็น lower triangular
  2. det = ผลคูณทแยงมุมหลัก = (-4)(2)(-3)(-1) = -24

สมบัติของ determinant กับการดำเนินการแถว:

การกระทำผลต่อ det
สลับสองแถว R_pqdet เปลี่ยนเครื่องหมาย
R_p + cR_qdet ไม่เปลี่ยนแปลง
คูณแถวด้วย c cR_pdet คูณด้วย c
สองแถวเหมือนกันdet = 0

สมบัติพีชคณิต: det A = det A^T, det(AB) = det A · det B, det(A^k) = (det A)^k, det(cA) = c^n · det A (n = ขนาดเมทริกซ์), A ไม่เอกฐาน ⟺ det A ≠ 0, ถ้า det ≠ 0 จะได้ det(A^-1) = 1/det A

ตัวอย่าง: ใช้สมบัติของ determinant
  1. ให้ det A = 2, det B = 3, det C = 4 (ทุกตัวขนาด 3×3) หา det(2AB^T C^-1)
  2. det(2AB^T C^-1) = 2^3 · det A · det B^T · det C^-1
  3. = 8 · 2 · 3 · (1/4) = 12 (ใช้ det B^T = det B และ det C^-1 = 1/det C)
ตัวอย่าง: cofactor expansion ทีละบรรทัด
  1. หา det [[1, 5, 0], [0, -3, 1], [2, 4, -1]] กระจายตามแถว 1 (มีศูนย์ 1 ตัว)
  2. det = 1·C11 + 5·C12 + 0·C13
  3. C11 = (+1)·det[[-3, 1], [4, -1]] = (3 - 4) = -1
  4. C12 = (-1)·det[[0, 1], [2, -1]] = -(0 - 2) = 2
  5. det = 1·(-1) + 5·(2) + 0 = -1 + 10 = 9

เมทริกซ์ผูกพัน (adjoint) adj A = transpose ของเมทริกซ์โคแฟกเตอร์ [Cij(A)]^T มีทฤษฎี A(adj A) = (adj A)A = (det A)·In จึงได้สูตร inverse A^-1 = (adj A)/(det A) เมื่อ det A ≠ 0

ตัวอย่าง: กฎของคราเมอร์ (Cramer's Rule)
  1. แก้ Ax = b เมื่อ det A ≠ 0 โดย xi = det(Ai) / det(A) เมื่อ Ai = เอาหลักที่ i ของ A เปลี่ยนเป็นเวกเตอร์ b
  2. ระบบ x1 - x2 + 2x3 = -2, 3x1 - 2x2 + 4x3 = -5, 2x2 - 5x3 = 2
  3. คำนวณได้ det A = -1, det A1 = 1, det A2 = -1, det A3 = 0
  4. x1 = 1/(-1) = -1, x2 = (-1)/(-1) = 1, x3 = 0/(-1) = 0
  5. ผลเฉลย x = (-1, 1, 0)
ข้อผิดพลาดที่พบบ่อย (2.4)
  • ลืมเครื่องหมาย (-1)^(i+j) ของ cofactor (ลำดับเครื่องหมาย + - + / - + - / + - +)
  • คิดว่า det(cA) = c·det A จริง ๆ ต้องเป็น c^n · det A
  • adj A คือ transpose ของเมทริกซ์โคแฟกเตอร์ ลืม transpose บ่อยมาก
  • Cramer ใช้ได้เฉพาะเมื่อ det A ≠ 0 และจำนวนสมการ = จำนวนตัวแปร เท่านั้น

3. Eigenvalue และ Diagonalization

3.1 เวกเตอร์พิกัดและเมทริกซ์ของการแปลงคนละฐานหลัก

  • เวกเตอร์พิกัด: ถ้า B = {v1, ..., vp} เป็นฐานหลักของ H และ x = c1v1 + ... + cpvp (ตัวเดียว) แล้ว [x]_B = (c1, ..., cp)
  • เมทริกซ์ของ T สัมพัทธ์กับฐานหลัก B และ C: [T]_CB = [ [T(v1)]_C [T(v2)]_C ... [T(vn)]_C ] ใช้สูตร [T(x)]_C = [T]_CB · [x]_B
  • การประกอบ (composition): [T∘S]_DB = [T]_DC [S]_CB และ [T^-1]_B = ([T]_B)^-1
  • เมทริกซ์การเปลี่ยนพิกัด P_{B→B'} = [ [v1]_B' [v2]_B' ... [vp]_B' ] ทำให้ [x]_B' = P_{B→B'}[x]_B และสองทิศเป็น inverse กัน
  • ความสัมพันธ์เมทริกซ์คนละฐานหลัก: [T]_B' = P^-1 [T]_B P เมทริกซ์แบบนี้เรียกว่า คล้ายกัน (similar)

3.2 Eigenvalue, Eigenvector และการแปลงเป็นทแยงมุม

นิยามสำคัญ
  • จำนวนจริง λ เป็น eigenvalue ของ A เมื่อ Ax = λx มีผลเฉลยไม่ชัด, เวกเตอร์ไม่ศูนย์ในผลเฉลยนั้นคือ eigenvector สมนัยกับ λ
  • สมการลักษณะเฉพาะ: det(A - λIn) = 0 / พหุนามลักษณะเฉพาะ: det(A - λIn) ดีกรี n
  • ปริภูมิลักษณะเฉพาะ (eigenspace): A_λ = Nul(A - λIn) = {0} + eigenvector ทั้งหมดของ λ
  • เช็กว่า λ เป็น eigenvalue: ดูว่า det(A - λI) = 0 หรือไม่ (ถ้า ≠ 0 แปลว่าไม่ใช่ เพราะมีแต่ผลเฉลยชัด)
  • เช็กว่า v เป็น eigenvector: คูณ Av แล้วดูว่าได้ทวีคูณของ v หรือไม่

วิธีหา eigenvalue / eigenvector ทีละขั้น:

  1. คำนวณ det(A - λI) แล้วแก้ = 0 จะได้ λ (นับซ้ำได้)
  2. สำหรับแต่ละ λ แก้ระบบเอกพันธุ์ (A - λI)x = 0 โดยลดรูปเป็นขั้นบันไดลดรูป
  3. เขียนผลเฉลยเป็น parametric vector form จะได้ฐานหลักของ eigenspace
ตัวอย่าง: หา eigenvalues และ eigenvectors ของ A = [[7, 2], [-4, 1]]
  1. A - λI = [[7-λ, 2], [-4, 1-λ]]
  2. det(A - λI) = (7-λ)(1-λ) + 8 = λ² - 8λ + 15 = (λ - 3)(λ - 5) = 0 จึงได้ λ = 3, 5
  3. λ = 3: A - 3I = [[4, 2], [-4, -2]] ∼ [[1, 1/2], [0, 0]] ได้ x1 = -(1/2)x2 เลือก x2 = 2 ได้ v = (-1, 2)
  4. λ = 5: A - 5I = [[2, 2], [-4, -4]] ∼ [[1, 1], [0, 0]] ได้ x1 = -x2 เลือก x2 = 1 ได้ v = (-1, 1)
  5. eigenspace ของ λ = 3 คือ Span{(-1, 2)} และของ λ = 5 คือ Span{(-1, 1)}

เมทริกซ์คล้าย (similar matrices): A คล้าย B เมื่อมี P ไม่เอกฐานที่ B = P^-1AP เมทริกซ์คล้ายกันมีพหุนามลักษณะเฉพาะและ eigenvalue ชุดเดียวกัน แต่มี characteristic polynomial เดียวกันไม่จำเป็นต้องคล้ายกัน

มักออกสอบ: ทฤษฎีบทการแปลงเป็นทแยงมุม (Diagonalization Theorem)
  • A ขนาด n แปลงเป็นทแยงมุมได้ (diagonalizable) ⟺ มี eigenvector อิสระเชิงเส้น n ตัว ⟺ มี P ไม่เอกฐานและ D ทแยงมุมที่ A = PDP^-1
  • หลักของ P = eigenvector, สมาชิกทแยงมุมของ D = eigenvalue ที่สมนัยกันตามลำดับ
  • ถ้า A มี eigenvalue ต่างกัน n ค่า → แปลงเป็นทแยงมุมได้ทันที
  • ถ้ามี eigenvalue ซ้ำ: ต้องมี nullity(A - λk·I) = จำนวนการซ้ำของ λk ทุกตัว (หรือผลรวมมิติ eigenspace = n) จึง diagonalizable
  • เวกเตอร์ลักษณะเฉพาะที่สมนัยกับ eigenvalue ต่างกัน เป็นเซตอิสระเชิงเส้น

วิธีแปลงเป็นทแยงมุมทีละขั้น: (1) หา det(A - λI) = 0 ได้ eigenvalues นับซ้ำ (2) หาฐานหลักของ eigenspace แต่ละ λ (3) เช็กว่ารวมแล้วได้ eigenvector อิสระ n ตัว (4) เรียง eigenvector เป็นหลักของ P และ eigenvalue ที่จับคู่กันเป็นทแยงมุมของ D จะได้ P^-1AP = D

ประโยชน์: คำนวณ A^k เร็ว เพราะ A = PDP^-1 และ D^k = diag(λ1^k, ..., λn^k) จึงได้ A^k = P D^k P^-1 สำหรับตัวอย่างเมทริกซ์ A = [[7, 2], [-4, 1]] ข้างบน ให้ P = [[-1, -1], [2, 1]], D = [[3, 0], [0, 5]] และมีสูตรปิดของ A^k ตามที่แสดงใน เฉลยข้อ 23

ข้อผิดพลาดที่พบบ่อย (บทที่ 3)
  • เวกเตอร์ศูนย์ไม่ใช่ eigenvector (แต่ eigenvalue เป็น 0 ได้, เกิดเมื่อ A เอกฐาน: A เอกฐาน ⟺ 0 เป็น eigenvalue)
  • จับคู่หลักของ P กับทแยงมุมของ D ไม่ตรงลำดับกัน
  • ตรวจ diagonalizable แล้วสรุปแค่ "มี eigenvalue ครบ n ตัว" โดยไม่เช็กว่า eigenspace มีมิติพอ (λ ซ้ำต้อง nullity = จำนวนซ้ำ)
  • เลือก eigenvector เป็นเศษส่วนเปลี่ยว ๆ ทั้งที่คูณด้วยจำนวนเต็มให้สะอาดได้ เช่น (1/3, 1) คูณ 3 เป็น (1, 3), ทำได้เพราะ eigenvector เป็นพหุคูณสเกลาร์กันได้

3.3 ระบบสมการเชิงอนุพันธ์ (Systems of Differential Equations)

ระบบ x' = Ax เมื่อ A diagonalizable มี eigenvector vi สมนัยกับ λi จะได้ผลเฉลยทั่วไป:

x(t) = C1·e^(λ1·t)·v1 + C2·e^(λ2·t)·v2 + ... + Cn·e^(λn·t)·vn

วิธีทำทีละขั้น: (1) เขียนเป็น x' = Ax (2) หา eigenvalues/vectors (3) เขียนผลเฉลยทั่วไป (4) ถ้ามีเงื่อนไขเริ่มต้น x(0) ให้แทน t = 0 แล้วแก้ระบบหา C_i ตัวอย่างคำนวณเต็มดูที่ ข้อ 24 ของแบบทดสอบ

4. Orthogonality

4.1 ผลคูณภายในและเซตเชิงตั้งฉาก

  • ผลคูณจุด (dot product): u·v = u^T v = u1v1 + u2v2 + ... + unvn (เป็นจำนวนจริง), สลับที่และแจกแจงได้, u·u ≥ 0 และ u·u = 0 ⟺ u = 0
  • ความยาว/นอร์ม: ‖v‖ = √(v·v) = √(v1² + ... + vn²), v·v = ‖v‖², ‖cv‖ = |c|·‖v‖
  • เวกเตอร์หนึ่งหน่วย ทิศเดียวกับ v คือ v/‖v‖ / ระยะทาง ระหว่าง x, y คือ ‖x - y‖ / ตั้งฉาก (orthogonal) ⟺ u·v = 0
  • เซตเชิงตั้งฉาก = คู่ใดคู่หนึ่งต่างกันตั้งฉากกัน / เซตเชิงตั้งฉากปรกติ (orthonormal) = ตั้งฉาก + ทุกตัวยาว 1 หน่วย
ทฤษฎีสำคัญ
  • เซตเชิงตั้งฉากที่ไม่มีเวกเตอร์ศูนย์ → อิสระเชิงเส้นเสมอ → เป็นฐานหลักของ Span ของมัน
  • ฐานหลักเชิงตั้งฉากทำให้แยกพิกัดง่าย: y = (y·u1)/(u1·u1) · u1 + (y·u2)/(u2·u2) · u2 + ... + (y·up)/(up·up) · up
  • เมทริกซ์ U มีหลัก orthonormal ⟺ U^T U = In
  • ถ้า U จัตุรัสเรียก เมทริกซ์เชิงตั้งฉาก (orthogonal matrix) มี U^-1 = U^T และรักษาความยาว/มุม (‖Ux‖ = ‖x‖, Ux·Uy = x·y)

4.2 การฉายเชิงตั้งฉากและกระบวนการ Gram-Schmidt

  • ส่วนเติมเต็มเชิงตั้งฉาก (orthogonal complement) H⊥ = { z : z ตั้งฉากกับทุกเวกเตอร์ใน H } เป็นปริภูมิย่อยและ H ∩ H⊥ = {0}
  • ถ้า H = Col A แล้ว H⊥ = Nul(A^T) เป็นเครื่องมือหลักในการหาฐานหลักของ H⊥ (ลดรูป A^T แก้ระบบเอกพันธุ์)

การแยกเชิงตั้งฉาก (Orthogonal Decomposition) ให้ {u1, ..., up} เป็นฐานหลักเชิงตั้งฉากของ H และ y ใด ๆ:

y = ŷ + z      โดย  ŷ = proj_H y = Σ (y·ui)/(ui·ui) · ui   อยู่ใน H
                    z = y - ŷ                              อยู่ใน H⊥

ŷ คือจุดบน H ใกล้ y ที่สุด (Best Approximation Theorem) และ ‖y - ŷ‖ คือระยะทางจาก y ไป H

กระบวนการ Gram-Schmidt แปลงฐานหลักใด ๆ เป็นฐานหลักเชิงตั้งฉาก:

v1 = x1
v2 = x2 - (x2·v1)/(v1·v1) · v1
v3 = x3 - (x3·v1)/(v1·v1) · v1 - (x3·v2)/(v2·v2) · v2
...
vk = xk - ผลรวม (xk·vi)/(vi·vi) · vi   (i = 1, ..., k-1)

จากนั้นทำให้เป็น orthonormal โดยหารด้วย ‖vi‖ และ Span คงเดิม ตัวอย่างคำนวณเต็มดูที่ ข้อ 21 ของแบบทดสอบ

การแยกตัวประกอบ QR (QR Factorization): ถ้าหลักของ A (m×n) อิสระ จะได้ A = QR เมื่อ Q (m×n) มีหลักเป็นฐานหลักเชิงตั้งฉากปรกติของ Col A และ R (n×n) เป็นเมทริกซ์สามเหลี่ยมบนไม่เอกฐาน ทแยงมุมเป็นบวก หาได้จาก R = Q^T A

ข้อผิดพลาดที่พบบ่อย (4.2)
  • ลืมตรวจว่าผลลัพธ์ Gram-Schmidt ตั้งฉากจริง (เช็ก v1·v2 = 0 ทุกครั้ง)
  • คูณเวกเตอร์ด้วยสเกลาร์เพื่อล้างเศษส่วนได้ (Span ไม่เปลี่ยน) แต่ถ้าจะต่อไปขั้นถัดไปต้องใช้เวกเตอร์ชุดที่เลือกนั้นต่อเนื่อง
  • สับสนว่า z = y - ŷ อยู่ใน H: จริง ๆ z ∈ H⊥
  • ใน QR ลืมว่า R = Q^T A และ Q ต้องมีหลักหนึ่งหน่วย (normalize ก่อน)

4.3 ปัญหากำลังสองน้อยสุด (Least-Squares)

เมื่อระบบ Ax = b ไม่มีผลเฉลย (b ไม่อยู่ใน Col A) ให้หา x̂ ที่ทำให้ ‖b - Ax̂‖ น้อยที่สุด เรียก x̂ ว่า ผลเฉลยกำลังสองน้อยสุด (least-squares solution)

ทฤษฎีบทหลัก: สมการปรกติ (normal equations)
  • x̂ เป็น least-squares solution ⟺ x̂ แก้ A^T A x̂ = A^T b (ระบบนี้ต้องกันเสมอ)
  • ค่าคลาดเคลื่อน (least-squares error) = ‖b - Ax̂‖
  • กรณีพิเศษ: ถ้าหลักของ A ตั้งฉากกันเอง หา x̂ ได้เร็วโดยฉาย: b̂ = Σ (b·ui)/(ui·ui)·ui = Ax̂

วิธีทำทีละขั้น: (1) คำนวณ A^T A และ A^T b (2) แก้ระบบ A^T A x̂ = A^T b ด้วยการลดรูปหรือ inverse (3) ถ้าต้องการ คำนวณ error ‖b - Ax̂‖

เส้นกำลังสองน้อยสุด (least-squares line) จากจุดข้อมูล (a1,b1), ..., (an,bn) หาเส้น y = β0 + β1x โดยสร้าง A หลักแรกเป็น 1 หมด หลักสองเป็นค่า x, β = (β0, β1), b = (b1, ..., bn) แล้วแก้ A^T A β̂ = A^T b

ตัวอย่าง: หาเส้นกำลังสองน้อยสุดจากจุด (0,1), (1,1), (2,2), (3,2)
  1. สร้าง A = [[1, 0], [1, 1], [1, 2], [1, 3]] และ b = (1, 1, 2, 2)
  2. A^T A = [[4, 6], [6, 14]] และ A^T b = (6, 11)
  3. แก้ [[4, 6], [6, 14]] β̂ = (6, 11) ได้ β̂ = (0.9, 0.4)
  4. เส้นกำลังสองน้อยสุดคือ y = 0.9 + 0.4x
ข้อผิดพลาดที่พบบ่อย (4.3)
  • ไปแก้ Ax = b ตรง ๆ (ซึ่งไม่มีผลเฉลย) แทนที่จะแก้ A^T A x̂ = A^T b
  • ลืม transpose เขียนเป็น A A^T: ผิด ต้องเป็น A^T A (ผลคูณแบบ n×n)
  • error เป็นระยะทาง (ต้องถอดราก) ไม่ใช่กำลังสอง

4.4 การแปลงเป็นทแยงมุมของเมทริกซ์สมมาตร

เมทริกซ์สมมาตร (symmetric matrix): A^T = A (a_ij = a_ji)

ทฤษฎีบทเชิงสเปกตรัม (Spectral Theorem)
  • ปริภูมิลักษณะเฉพาะที่สมนัยกับ eigenvalue ต่างกันของเมทริกซ์สมมาตร ตั้งฉากกัน
  • A เป็นสมมาตร ⟺ A orthogonally diagonalizable คือมี P เชิงตั้งฉากปรกติ (P^-1 = P^T) ที่ A = PDP^-1 = PDP^T
  • eigenvalues ของเมทริกซ์สมมาตรเป็นจำนวนจริงทั้งหมด และมิติของ eigenspace = จำนวนซ้ำของราก

วิธีแปลงเมทริกซ์สมมาตรเป็นทแยงมุมเชิงตั้งฉาก ทีละขั้น: (1) หา eigenvalues จาก det(A - λI) = 0 (2) หาฐานหลักของแต่ละ eigenspace (3) ถ้า eigenspace ใดมีมิติ > 1 ใช้ Gram-Schmidt ทำให้ตั้งฉาก (4) normalize ทุกเวกเตอร์ให้ยาว 1 เรียงเป็นหลักของ P (5) D = diag(eigenvalues ที่จับคู่ตามลำดับกับหลักของ P) จะได้ A = PDP^T ตัวอย่างคำนวณเต็มดูที่ ข้อ 25 ของแบบทดสอบ

การแยกเชิงสเปกตรัม (spectral decomposition) เขียน A ซ้ำได้เป็น A = λ1·u1u1^T + λ2·u2u2^T + ... + λn·unun^T เมื่อ ui เป็น eigenvector หนึ่งหน่วย เซตของ eigenvalue ทั้งหมดเรียกว่า สเปกตรัม (spectrum) ของ A

4.5 รูปแบบกำลังสอง (Quadratic Forms)

ให้ A เป็นเมทริกซ์สมมาตร ฟังก์ชัน Q(x) = x^T A x เรียกรูปแบบกำลังสอง การเขียนเมทริกซ์ของ Q จากพจน์:

  • สัมประสิทธิ์ของ x1², x2², ... → ลงทแยงมุมหลัก
  • พจน์ไขว้ (cross-product term) 2c·xi·xj → ใส่ c ลงตำแหน่งสมมาตร (i,j) และ (j,i) เช่น Q = 3x1² + 6x2² - 4x1x2 → A = [[3, -2], [-2, 6]]

ทฤษฎีบทแกนมุขสำคัญ (Principal Axis Theorem): เปลี่ยนตัวแปร x = Py (P เชิงตั้งฉากปรกติที่ทำให้ P^T AP = D) จะได้ x^T A x = y^T D y = λ1y1² + λ2y2² + ... หมดพจน์ไขว้ ใช้จำแนกรูปกรวย เช่น 3x1² + 6x2² - 4x1x2 = 14 → 2y1² + 7y2² = 14 (วงรี)

การจำแนกประเภทด้วย eigenvalues ของเมทริกซ์ของ Q:

Q(x) = x^T A xเงื่อนไข
บวกแน่นอน (positive definite)eigenvalues ทุกตัว > 0
บวกกึ่งแน่นอน (positive semidefinite)ทุกตัว ≥ 0
ลบแน่นอน (negative definite)ทุกตัว < 0
ลบกึ่งแน่นอนทุกตัว ≤ 0
ไม่แน่นอน (indefinite)มีทั้งบวกและลบ
ข้อผิดพลาดที่พบบ่อย (4.5)
  • เขียนสัมประสิทธิ์พจน์ไขว้ลงเมทริกซ์แบบไม่หาร 2 เช่น -4x1x2 ต้องลงเป็น -2 ในเมทริกซ์ เพราะเมทริกซ์นับสองทาง

5. ปริภูมิเวกเตอร์นามธรรม

5.1 ฟีลด์ ปริภูมิเวกเตอร์ และปริภูมิย่อย

  • ฟีลด์ (field) F: เซตที่มีการบวก/คูณครบสมบัติ (ปิด, เปลี่ยนหมู่, สลับที่, เอกลักษณ์ 0 และ 1, ตัวผกผัน, แจกแจง) เช่น Q, R, C และ F_p = {0, 1, ..., p-1} (เลขคณิตมอดุโล p เมื่อ p เป็นจำนวนเฉพาะ)
  • ปริภูมิเวกเตอร์ V เหนือฟีลด์ F: เซตพร้อมการบวกและการคูณสเกลาร์ที่สอดคล้องสมบัติ: ปิดบวก, เปลี่ยนหมู่, มีเวกเตอร์ศูนย์, สลับที่, มีตัวผกผันการบวก และ c(v1+v2) = cv1+cv2, (c1c2)v = c1(c2v), (c1+c2)v = c1v+c2v, 1v = v รวมทั้ง 0v = 0, (-1)v = -v
  • ตัวอย่างปริภูมิเวกเตอร์: M_{m,n}(F) (เมทริกซ์ m×n), F^m, ปริภูมิลำดับ F^N, ปริภูมิฟังก์ชัน F^S, ปริภูมิพหุนาม F_n[x] (ดีกรีไม่เกิน n), ผลคูณตรง V1 × ... × Vn
  • ปริภูมิย่อย W ของ V: ต้องมี 0_V ∈ W และปิดภายใต้ v1 + c·v2 (เช็ก 2 อย่างพอ)
  • Span, อิสระเชิงเส้น, ฐานหลัก (อิสระ + แผ่ทั่ว), มิติ นิยามเหมือนบทที่ 1-2 แต่ใช้กับวัตถุนามธรรมได้ทั้งหมด
มักออกสอบ: มิติที่ควรจำ
  • dim M_{m,n}(F) = mn
  • dim F_n[x] = n + 1 (ฐานหลักมาตรฐาน {1, x, x², ..., x^n})
  • F[x] (พหุนามทุกดีกรี) ไม่มีมิติจำกัด
  • C เหนือ R มีฐานหลัก {1, i}

5.2 การแปลงเชิงเส้นบนปริภูมินามธรรม

  • T: V → W เป็นการแปลงเชิงเส้น ⟺ T(u+v) = T(u)+T(v) และ T(cv) = cT(v)
  • นิยาม T ได้โดยกำหนดค่าบนฐานหลักเท่านั้น (มี T ตามกำหนดนี้ตัวเดียวและมีอยู่เสมอ)
  • เคอร์เนล (kernel): ker T = {v : T(v) = 0_W} เป็นปริภูมิย่อยของ V
  • เรนจ์ (range): range T = {T(v) : v ∈ V} เป็นปริภูมิย่อยของ W
  • T มีสมบัติ 1-1 ⟺ ker T = {0} / ทั่วถึง ⟺ range T = W ⟺ rank T = dim W
  • nullity T = dim ker T, rank T = dim range T
  • สมสัณฐาน (isomorphic) V ≅ W: มี T ที่ 1-1 และทั่วถึง ⟺ dim V = dim W (มิติจำกัด), ปริภูมิมิติ n ใด ๆ สมสัณฐานกับ F^n
  • ปริภูมิคู่เสมอกัน (dual space) V* = L(V, F) = เซตของ linear functional, มีฐานหลักคู่เสมอกัน (dual basis) และ V ≅ V*
  • เมทริกซ์ของ T สัมพัทธ์กับฐานหลัก [T]_CB ทำงานเหมือนบทที่ 3 และ L(V,W) ≅ M_{m,n}(F)

5.3 ปริภูมิผลคูณภายใน (Inner Product Space)

  • ผลคูณภายใน ⟨u,v⟩ ต้องมีสมบัติ: (1) ⟨u,u⟩ ≥ 0 และ = 0 ⟺ u = 0 (2) แจกแจง (3) ⟨cv,w⟩ = c⟨v,w⟩ (4) ⟨v,w⟩ = ⟨w,v⟩ (สังยุค conjugate กรณีเชิงซ้อน)
  • ตัวอย่าง: ผลคูณมาตรฐาน Σ ui·vi, ผลคูณถ่วงน้ำหนัก Σ ai·ui·vi, ⟨f,g⟩ = ∫ f(x)g(x)dx บน C0[a,b]
  • นอร์ม: ‖v‖ = √⟨v,v⟩
  • อสมการโคชี-ชวาร์ซ: |⟨u,v⟩| ≤ ‖u‖‖v‖ / อสมการสามเหลี่ยม: ‖u+v‖ ≤ ‖u‖ + ‖v‖
  • เซตเชิงตั้งฉาก (ไม่มีศูนย์) อิสระเชิงเส้น และมี Gram-Schmidt เวอร์ชันทั่วไป
v_k = x_k - Σ (⟨x_k, v_i⟩ / ⟨v_i, v_i⟩) · v_i   (i รวมทุกค่าน้อยกว่า k)

ปริภูมิผลคูณภายในมิติจำกัดจึงมีฐานหลักเชิงตั้งฉากปรกติเสมอ

ข้อผิดพลาดที่พบบ่อย (บทที่ 5)
  • จำ dim F_n[x] เป็น n: ผิด! ต้องเป็น n + 1 เพราะนับพจน์ {1, x, ..., x^n}
  • เช็กปริภูมิย่อยลืมดูว่า 0_V ∈ W ก่อน ถ้า 0 ไม่อยู่ก็จบ ไม่เป็นปริภูมิย่อยทันที
  • สับสนว่า ker T เป็นปริภูมิย่อยของ W: จริง ๆ ker T เป็นปริภูมิย่อยของ V ส่วน range T เป็นปริภูมิย่อยของ W
  • ตัดสินสมสัณฐานโดยไม่ดูมิติ: V ≅ W เมื่อมิติเท่ากัน (กรณีมิติจำกัด) เท่านั้น
